Connect to Google Sheets

CloudPOS Pro stores all data in your own Google Sheet. Do the one-time setup below, paste your Web App URL, and you're done. The URL is remembered on this device.

One-time setup steps

  1. Open sheets.google.com and create a new blank sheet.
  2. Menu: Extensions → Apps Script.
  3. Delete the sample code, paste the script you were given, click Save.
  4. Click Deploy → New deployment.
  5. Type = Web app; Execute as = Me; Access = Anyone.
  6. Click Deploy, allow access when asked.
  7. Copy the Web app URL (ends in /exec) and paste it below.

Already connected on another device? Just paste the same URL here.
